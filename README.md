## 📌 Project Overview  
This project presents an **Autonomous Disaster Management Drone System** developed using **Webots + ROS**.  
The system integrates:

- ✔️ Autonomous Navigation
- ✔️ Ground Penetrating Radar (GPR) Simulation
- ✔️ YOLO-based Human Detection
- ✔️ PID-based Stable Control
- ✔️ ROS + Webots Communication Bridge
- ✔️ Real-time Telemetry + Command Handling

The project is focused on **Search & Rescue missions** in complex disaster environments where the drone detects:
- 👁️ Surface victims using camera  
- 🛰️ Buried victims using GPR  

---

## 🧠 Key Features  
🔹 Fully autonomous coverage scanning navigation  
🔹 Real-time human detection using YOLO  
🔹 GPR B-Scan + Subsurface Visualization  
🔹 Stable & smooth flight using PID controller  
🔹 ROS command + telemetry bridge  
🔹 Automatic logging and visualization  
🔹 Works inside realistic Webots disaster environment
